# Fifine K420 Studio

Десктопное приложение для веб-камеры **Fifine K420** (2K 2560×1440 @ 30 к/с, фиксированный фокус, встроенный микрофон).
Работает и с любой другой UVC-камерой.

## Возможности

**Камера**
- выбор камеры и драйвера захвата (DirectShow / Media Foundation в Windows, V4L2 в Linux);
- разрешение 2560×1440, 1920×1080, 1280×720, 640×480; частота 5–30 к/с;
- формат потока MJPG (нужен для 2K/1080p@30) или YUY2 (несжатый);
- зеркало и поворот на 180°.

**Изображение (UVC)** — применяется сразу
- яркость, контрастность, насыщенность, оттенок, резкость, гамма, усиление;
- баланс белого (авто / ручной в Кельвинах), экспозиция (авто / ручная);
- компенсация засветки, цифровой зум, панорама, наклон;
- «Считать с камеры», «Сбросить», окно драйвера DirectShow (Windows; там же частота сети 50/60 Гц против мерцания).

**Микрофон**
- выбор устройства (микрофон K420 находится автоматически), 16–48 кГц, моно/стерео;
- программное усиление −20…+30 дБ, шумоподавитель (noise gate);
- индикатор уровня с предупреждением о клиппинге, прослушивание в наушниках.

**Запись** (FFmpeg)
- кодеки: H.264/H.265 (x264/x265), NVIDIA NVENC, Intel Quick Sync, AMD AMF, MPEG-4 — показываются только реально работающие на этом ПК;
- режимы битрейта: **CBR**, **VBR**, **CQ/CRF** (постоянное качество);
- битрейт видео 300–80 000 кбит/с, пресет скорости, интервал ключевых кадров;
- звук AAC / Opus / MP3, 64–320 кбит/с; контейнеры MP4, MKV, MOV;
- расчёт размера файла (МБ/мин), снимки PNG;
- постоянная частота кадров с синхронизацией по часам — звук не «уезжает», даже если камера в темноте снижает fps.

**Профили** — встроенные («Стрим 1080p30», «Макс. качество 1440p», «Видеозвонок 720p», «Слабый ПК»), свои, импорт/экспорт JSON. Последние настройки запоминаются.

## Запуск из исходников

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Linux: дополнительно `sudo apt install libportaudio2 v4l-utils` (звук и точные диапазоны параметров).

## Сборка через GitHub Actions

1. Создайте репозиторий и загрузите в него содержимое архива (папка `.github` обязательна).
2. При каждом push в `main`/`master` запускаются линтер, тесты и сборка для Windows и Linux.
   Готовые архивы — во вкладке **Actions → нужный запуск → Artifacts**.
3. Чтобы создать релиз с файлами:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   Сборки появятся во вкладке **Releases**.

Локальная сборка: `pip install pyinstaller` и
`pyinstaller --noconfirm --windowed --name FifineK420Studio --collect-all imageio_ffmpeg run.py`.

## Примечания

- Камеру одновременно может использовать только одна программа — закройте Zoom/OBS/Teams перед запуском.
- Если в списке камер имена перепутаны (бывает при нескольких камерах), просто выберите другой номер.
- Сама UVC-камера не имеет настройки битрейта: поток идёт в MJPG/YUY2. Битрейт задаётся при кодировании записи.
- Аппаратная громкость микрофона K420 настраивается в системе (Параметры звука → Ввод), в приложении — дополнительное программное усиление.
- Диапазоны параметров изображения зависят от драйвера. Если реальное значение камеры выходит за диапазон слайдера, диапазон расширяется автоматически.
